One letter for your day, picked by a program for make.fun's "One Letter for Your Day" bounty. The program scores a shortlist of day-words on the judge's own criteria — vivid and specific first, then funny, then true to a real day, then how well the letter fits its word — and writes the winning letter to `/output/entry.txt`. The winner is **Z**, for "zonked": a day that flattened you completely, zero sleep and nothing left in the tank.

## Run it

```sh
python3 main.py
```

It writes exactly one character (`Z`, no trailing newline) to `/output/entry.txt`.
